# AI Course Projects

A monorepo repository containing projects built during the AI Course. This repository demonstrates building the same applications using different AI agent frameworks and setups, as well as experiments with various AI capabilities like skills, hooks, and agents.

## Repository Architecture

```text
AI Course Projects/
├── week-1-full-stack-kanban-app/     # Full-stack Kanban application
├── week-1-kanban-app-antigravity/    # Kanban application built with Antigravity
├── week-1-kanban-app-opencode/       # Kanban application built with OpenCode
├── week-1-portfolio-app-opencode/    # Portfolio application built with OpenCode
├── week-3-finally-app/               # Finally application (Week 3)
├── .gitignore                        # Root Git ignore rules
└── readme.md                         # Repository overview and documentation
```

## Branches & Different AI Agents

The same applications are built using different AI agents and frameworks, organized into various branches:

- `week-1-kanban-app-antigravity`: Kanban app built using the **Antigravity** agent.
- `week-1-kanban-app-opencode`: Kanban app built using the **OpenCode** agent.
- `week-1-full-stack-kanban-app-antigravity`: Full-stack Kanban app built using **Antigravity**.
- `week-3-finally-app`: Base Finally app.
- `week-3-finally-app-gsd-swarms`: Finally app built using **GSD Swarms**.
- `week-3-finally-app-with-agent-teams-antigravity`: Finally app built using **Antigravity Agent Teams**.

## Experiments

Throughout the course, various experiments were conducted to explore different AI agent capabilities. These are captured in different commits in the repository history:

- **Hooks Experiment**: Exploring and implementing AI hooks (`Hook practiced - week 3`).
- **Agent Experiment**: General agent setup and execution (`Agent practiced - week 3`).
- **Multi-Agent Experiment**: Coordinating multiple agents to work together (`Multi Agent practiced - week 3`).
- **Skills Experiment**: Implementing specialized AI skills (`Skill practiced - week 3`).
