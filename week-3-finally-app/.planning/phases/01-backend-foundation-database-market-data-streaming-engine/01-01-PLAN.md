<objective>
Establish the core server-side foundation for FinAlly, an AI trading workstation backend built with FastAPI and Python 3.12 managed via `uv`.

This plan covers:
1. Initial backend structure setup with `uv` dependency management (`pyproject.toml`) and `/api/health` health check endpoint (**BACK-01**).
2. Asynchronous SQLite persistence layer with lazy schema auto-initialization (`db/finally.db`) for 6 core tables (**DB-01**) and database seeding ($10,000 default profile, 10 default tickers in watchlist) (**DB-02**).
3. In-memory, thread-safe price cache storing live prices, previous prices, direction, change, and versioning (**MKT-02**).
4. Market data streaming engine with abstract provider interface supporting an in-process Geometric Brownian Motion (GBM) simulator with Cholesky sector correlation matrix and optional Polygon.io REST client fallback (**MKT-01**).
5. Real-time Server-Sent Events (SSE) price stream endpoint `/api/stream/prices` delivering ~500ms ticker updates (**MKT-03**).
6. Comprehensive test suite under `backend/tests/` executed via `uv run pytest`.
</objective>

   - Define DDL statements for all 6 core tables:
     - `users_profile` (`id` TEXT PRIMARY KEY DEFAULT 'default', `cash_balance` REAL DEFAULT 10000.0, `created_at` TEXT)
     - `watchlist` (`id` TEXT PRIMARY KEY, `user_id` TEXT DEFAULT 'default', `ticker` TEXT, `added_at` TEXT, UNIQUE(user_id, ticker))
     - `positions` (`id` TEXT PRIMARY KEY, `user_id` TEXT DEFAULT 'default', `ticker` TEXT, `quantity` REAL, `avg_cost` REAL, `updated_at` TEXT, UNIQUE(user_id, ticker))
     - `trades` (`id` TEXT PRIMARY KEY, `user_id` TEXT DEFAULT 'default', `ticker` TEXT, `side` TEXT CHECK(side IN ('buy', 'sell')), `quantity` REAL, `price` REAL, `executed_at` TEXT)

     - `chat_messages` (`id` TEXT PRIMARY KEY, `user_id` TEXT DEFAULT 'default', `role` TEXT CHECK(role IN ('user', 'assistant')), `content` TEXT, `actions` TEXT, `created_at` TEXT)

   - `init_db(db_path: Path) -> None`:
     - Create parent directories (`db_path.parent.mkdir(parents=True, exist_ok=True)`).
     - Connect via `aiosqlite.connect(db_path)`.
     - Execute script `CREATE_TABLES_SQL` and commit.
     - Check if `users_profile` has row with `id='default'`. If not, insert default row with `cash_balance=10000.0`.
     - Check if `watchlist` has any rows for `user_id='default'`. If count is 0, bulk insert the 10 `DEFAULT_TICKERS` with generated UUIDs and ISO timestamps.

3. Create `backend/tests/test_database.py`:
   - Test `init_db` against a temporary SQLite file (`tmp_path / "test.db"`).
   - Assert all 6 tables exist by querying `sqlite_master`.
   - Assert `users_profile` table contains `id='default'` with `cash_balance == 10000.0`.
   - Assert `watchlist` table contains exactly 10 rows matching `DEFAULT_TICKERS`.
   - Assert calling `init_db` twice is idempotent (does not duplicate seed records).
</details>

<step>
Build data models for price updates, abstract class for market data providers, and a thread-safe in-memory cache with version tracking for broadcast synchronization.
</step>
<details>
1. Create `backend/app/market/models.py`:
   - Define Pydantic model `PriceUpdate`:
     - `ticker`: `str`
     - `price`: `float`
     - `previous_price`: `float`
     - `timestamp`: `str` (ISO-8601 format)
     - `change`: `float`
     - `direction`: `Literal["up", "down", "flat"]`

2. Create `backend/app/market/interface.py`:
   - Define abstract base class `MarketDataSource(ABC)`:
     - `@abstractmethod async def start(self) -> None`: Start continuous background tick polling/generation.
     - `@abstractmethod async def stop(self) -> None`: Gracefully stop background task.
     - `@abstractmethod def add_ticker(self, ticker: str) -> None`: Add ticker to track.
     - `@abstractmethod def remove_ticker(self, ticker: str) -> None`: Remove ticker from tracking.
     - `@abstractmethod def get_tickers(self) -> List[str]`: Return current active ticker list.

3. Create `backend/app/market/cache.py`:
   - Class `PriceCache`:
     - Private `_lock = threading.Lock()`, `_cache: Dict[str, PriceUpdate] = {}`, `_version: int = 0`.
     - Property `version -> int`: Return current `_version` under lock.
     - `set(update: PriceUpdate) -> None`: Update single ticker, increment `_version` by 1.
     - `set_many(updates: List[PriceUpdate]) -> None`: Bulk update tickers, increment `_version` by 1.
     - `get(ticker: str) -> Optional[PriceUpdate]`: Return copy or reference to cached update.
     - `get_all() -> Dict[str, PriceUpdate]`: Return dictionary snapshot of all cached prices.

4. Create `backend/tests/test_cache.py`:
   - Test initial empty cache state and version `0`.
   - Test single `set()` and bulk `set_many()` update operations.
   - Assert `version` increments properly with each update.
   - Test `get()` for existing vs non-existing tickers.
   - Test concurrent writes using multiple threads to ensure thread-safety.
</details>

<name>Geometric Brownian Motion Simulator & Polygon.io Client Fallback (MKT-01)</name>
<files>

<step>
Implement the Geometric Brownian Motion (GBM) market simulator with Cholesky sector correlation matrix, shock event generation, 500ms tick interval, and Polygon.io REST client integration.
</step>
<details>
1. Create `backend/app/market/simulator.py`:
   - Implement `GBMSimulator` class:
     - Initialize with baseline stock prices (`AAPL`: 180.0, `GOOGL`: 140.0, `MSFT`: 400.0, `AMZN`: 175.0, `TSLA`: 200.0, `NVDA`: 850.0, `META`: 485.0, `JPM`: 195.0, `V`: 280.0, `NFLX`: 600.0).
     - Construct sector correlation matrix (e.g. 10x10 matrix where tech tickers AAPL, GOOGL, MSFT, AMZN, TSLA, NVDA, META share ~0.6 correlation, finance JPM/V share ~0.5 correlation, cross-sector ~0.3).
     - Compute Cholesky decomposition `L = np.linalg.cholesky(corr_matrix)`.
     - Method `tick() -> List[PriceUpdate]`:
       - Generate standard normal random vector `Z`.
       - Compute correlated noise `correlated = L @ Z`.
       - Apply GBM formula with time step `dt = 0.5 / 86400.0`, drift `mu = 0.0001`, volatility `sigma = 0.015`.
       - Add random shock check (~0.1% chance per tick for ±5% price move).
       - Ensure price floor `max(0.01, price)` rounded to 2 decimal places.
       - Return `List[PriceUpdate]`.
   - Implement `SimulatorDataSource(MarketDataSource)`:
     - Background `asyncio.Task` running `tick()` every 500ms (`await asyncio.sleep(0.5)`).
     - Updates `PriceCache` on every tick loop iteration.

2. Create `backend/app/market/massive_client.py`:
   - Implement `MassiveDataSource(MarketDataSource)` using `massive-api` (Polygon.io client).
   - Poll real market prices via REST client at configurable intervals when `MASSIVE_API_KEY` is provided.
   - Update `PriceCache` with retrieved tick prices.

3. Create `backend/app/market/factory.py`:
   - `create_market_data_source(settings: Settings, cache: PriceCache) -> MarketDataSource`:
     - If `settings.MASSIVE_API_KEY` is non-empty, instantiate `MassiveDataSource`.
     - Otherwise, instantiate `SimulatorDataSource` with default tickers and initial prices.

4. Create `backend/tests/test_simulator.py`:
   - Test single `tick()` call generates valid `PriceUpdate` list for all tickers.
   - Test that generated prices remain positive and rounded to 2 decimal places.
   - Test sector correlation by running 500 ticks and computing output price sample covariance.
   - Test `SimulatorDataSource` start and stop lifecycle.
</details>

<name>SSE Price Streaming Endpoint & FastAPI Lifespan Context Integration (MKT-03)</name>
<files>

</files>
<step>
Implement the Server-Sent Events (SSE) streaming endpoint `/api/stream/prices` using `sse-starlette` and wire global application lifespan startup/shutdown hooks.
</step>
<details>
1. Create `backend/app/api/stream.py`:
   - Function `create_stream_router(cache: PriceCache) -> APIRouter`:
     - Endpoint `GET /api/stream/prices`:
       - Define async generator `event_generator(request: Request)`:
         - Maintain `last_version = -1`.
         - Loop while True:
           - Check `if await request.is_disconnected(): break`.
           - Compare `current_version = cache.version`.
           - If `current_version != last_version`:
             - Update `last_version = current_version`.
             - Fetch `all_ticks = cache.get_all()`.
             - Serialize list of tick dicts to JSON string.
             - Yield dict `{"event": "price_update", "data": json_payload}`.
           - Sleep `await asyncio.sleep(0.5)`.
       - Return `EventSourceResponse(event_generator(request))`.

2. Update `backend/app/main.py`:
   - Implement `@asynccontextmanager async def lifespan(app: FastAPI)`:
     - On startup:
       - Get settings via `get_settings()`.
       - Initialize database via `await init_db(settings.DB_PATH)`.
       - Instantiate global `PriceCache()`.
       - Create market source via `create_market_data_source(settings, app.state.price_cache)`.
       - Store `app.state.price_cache` and `app.state.market_source`.
       - Start background task `asyncio.create_task(app.state.market_source.start())`.
       - Include SSE stream router created with `app.state.price_cache`.
       - Yield.
     - On shutdown:
       - Cancel and await `app.state.market_source.stop()`.

3. Create `backend/tests/test_stream.py`:
   - Use `httpx.AsyncClient` with `ASGITransport(app=app)` to connect to `GET /api/stream/prices`.
   - Seed price updates in `PriceCache`.
   - Read initial stream chunk and assert header `content-type` contains `text/event-stream`.
   - Validate received SSE event format containing `event: price_update` and valid JSON data matching price updates.
</details>
