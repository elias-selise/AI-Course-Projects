<objective>
Build the portfolio accounting engine, market order trade execution engine, automated snapshot background service, and watchlist management REST APIs for FinAlly.

This plan covers:
1. Pydantic request/response schemas for portfolio valuation, trade execution, snapshot history, and watchlist items.
2. Portfolio calculation service and `GET /api/portfolio` endpoint returning real-time market value, cash balance, positions, and unrealized P&L (**PORT-01**).
3. Trade execution engine and `POST /api/portfolio/trade` endpoint supporting market buy/sell orders, enforcing cash/position validation, maintaining weighted average cost basis on buys, preserving cost basis on sells, logging trade rows, and triggering instant snapshots (**PORT-02**).
4. Background snapshot service (`SnapshotTask`) running every 30s and `GET /api/portfolio/history` endpoint returning chronological portfolio value history (**PORT-03**).
5. Watchlist management REST endpoints `GET /api/watchlist`, `POST /api/watchlist`, and `DELETE /api/watchlist/{ticker}` with dynamic ticker tracking in the market data engine (**WATCH-01**).
6. Comprehensive automated test suite under `backend/tests/` executed via `uv run pytest`.
</objective>

<name>Tracer Bullet: Portfolio Schemas, P&L Valuation Engine & GET /api/portfolio Endpoint (PORT-01)</name>

<step>
Implement the Pydantic data schemas for portfolio objects and the portfolio valuation service that computes positions value, total portfolio value, and unrealized P&L using live market prices from `PriceCache`.
</step>
<details>
1. Create `backend/app/schemas/portfolio.py`:
   - `TradeRequest`: `ticker: str` (sanitized uppercase, min length 1), `side: Literal["buy", "sell"]`, `quantity: float` (`Field(gt=0)`).
   - `TradeResponse`: `trade_id: str`, `ticker: str`, `side: Literal["buy", "sell"]`, `quantity: float`, `price: float`, `total_value: float`, `cash_balance: float`, `executed_at: str`.
   - `PositionItem`: `ticker: str`, `quantity: float`, `avg_cost: float`, `current_price: float`, `market_value: float`, `unrealized_pnl: float`, `unrealized_pnl_percent: float`.
   - `PortfolioResponse`: `cash_balance: float`, `positions_value: float`, `total_value: float`, `total_unrealized_pnl: float`, `total_unrealized_pnl_percent: float`, `positions: List[PositionItem]`.
   - `SnapshotResponse`: `id: str`, `total_value: float`, `recorded_at: str`.
   - `WatchlistAddRequest`: `ticker: str` (sanitized uppercase, min length 1).
   - `WatchlistItemResponse`: `id: str`, `ticker: str`, `price: float`, `previous_price: float`, `change: float`, `direction: Literal["up", "down", "flat"]`, `added_at: str`.

2. Create `backend/app/services/portfolio_service.py`:
   - `calculate_portfolio(db: aiosqlite.Connection, cache: PriceCache, user_id: str = "default") -> PortfolioResponse`:
     - Read `cash_balance` from `users_profile` for `user_id`.
     - Fetch all rows from `positions` where `quantity > 0` and `user_id = user_id`.
     - For each position, query live price from `cache.get(ticker)`. Fallback to `avg_cost` if price missing.
     - Calculate:
       - `market_val = round(qty * current_price, 2)`
       - `cost_basis = round(qty * avg_cost, 2)`
       - `pnl = round(market_val - cost_basis, 2)`
       - `pnl_pct = round((pnl / cost_basis * 100.0), 2)` if `cost_basis > 0` else `0.0`.
     - Sum `positions_value` and `total_cost_basis`.
     - Calculate `total_value = round(cash_balance + positions_value, 2)`.
     - Calculate `total_pnl = round(positions_value - total_cost_basis, 2)`.
     - Calculate `total_pnl_pct = round((total_pnl / total_cost_basis * 100.0), 2)` if `total_cost_basis > 0` else `0.0`.
     - Return `PortfolioResponse`.

3. Create `backend/app/api/portfolio.py`:
   - APIRouter with prefix `/api/portfolio`, tag `"Portfolio"`.
   - Endpoint `GET /api/portfolio`:
     - Obtain `PriceCache` from `request.app.state.price_cache`.
     - Get DB connection via `get_db(settings.DB_PATH)`.
     - Call `calculate_portfolio(db, cache)` and return response.

4. Create `backend/tests/test_portfolio.py`:
   - `test_get_portfolio_initial()`: Assert GET `/api/portfolio` on initial seeded DB returns `$10,000.0` cash, empty positions list, `$0.0` positions value, `$10,000.0` total value, and `$0.0` unrealized P&L.
   - `test_get_portfolio_with_positions()`: Manually insert a position into `positions` table, seed price in `PriceCache`, call GET `/api/portfolio`, and assert position market value, unrealized P&L, and total value match exact expected calculations.
</details>

<task id="02-01-02" type="expansion">
<name>Trade Execution Engine with Weighted Average Cost Basis & Atomic Transactions (PORT-02)</name>
<files>
- backend/app/services/portfolio_service.py
- backend/app/api/portfolio.py
- backend/tests/test_portfolio.py
</files>
<step>
Implement market order trade execution logic with strict balance validation, weighted average cost basis calculation on stock buys, cost basis preservation on stock sells, atomic SQLite transactions, and post-trade snapshot recording.
</step>
<details>
1. Update `backend/app/services/portfolio_service.py`:
   - Implement `execute_trade(db: aiosqlite.Connection, cache: PriceCache, trade_req: TradeRequest, user_id: str = "default") -> TradeResponse`:
     - Fetch live price from `cache.get(trade_req.ticker)`.
     - If price unavailable or `<= 0`, raise `ValueError(f"Market price unavailable for ticker: {trade_req.ticker}")`.
     - Calculate execution cost `trade_cost = round(qty * price, 2)`.
     - Query `cash_balance` from `users_profile`.
     - Query existing position `(quantity, avg_cost)` from `positions`.
     - Handle BUY side:
       - Assert `current_cash >= trade_cost`, else raise `ValueError("Insufficient funds...")`.
       - Compute `new_cash = round(current_cash - trade_cost, 2)`.
       - Compute `new_qty = round(existing_qty + qty, 4)`.
       - Compute weighted average cost: `new_avg_cost = round(((existing_qty * existing_avg_cost) + (qty * price)) / new_qty, 2)`.
     - Handle SELL side:
       - Assert `existing_qty >= qty`, else raise `ValueError("Insufficient position...")`.
       - Compute `new_cash = round(current_cash + trade_cost, 2)`.
       - Compute `new_qty = round(existing_qty - qty, 4)`.
       - Preserve cost basis: `new_avg_cost = existing_avg_cost if new_qty > 0 else 0.0`.
     - Perform atomic SQLite updates:
       - `UPDATE users_profile SET cash_balance = ? WHERE id = ?`
       - Upsert position using `INSERT INTO positions ... ON CONFLICT(user_id, ticker) DO UPDATE SET quantity = excluded.quantity, avg_cost = excluded.avg_cost, updated_at = excluded.updated_at`.
       - `INSERT INTO trades (id, user_id, ticker, side, quantity, price, executed_at) VALUES (...)`.
       - Call `record_snapshot(db, cache, user_id)` to trigger an immediate snapshot.
       - Commit transaction `await db.commit()`.
     - Return `TradeResponse`.

2. Update `backend/app/api/portfolio.py`:
   - Endpoint `POST /api/portfolio/trade`:
     - Accept `TradeRequest` body.
     - Call `execute_trade()`. Catch `ValueError` and raise `HTTPException(status_code=400, detail=str(e))`.

3. Expand `backend/tests/test_portfolio.py`:
   - `test_trade_buy_success()`: Execute BUY 10 shares AAPL at price $150.0. Assert cash decreases by $1500.0, position AAPL quantity is 10, avg_cost is $150.0, and trade audit log row exists.
   - `test_trade_buy_weighted_average_cost()`: BUY 10 AAPL at $100.0, then BUY 10 AAPL at $200.0. Assert position quantity is 20 and avg_cost is $150.0.
   - `test_trade_buy_insufficient_funds()`: Attempt BUY 1000 shares at $500.0 with $10,000 cash. Assert HTTP 400 response with "Insufficient funds".
   - `test_trade_sell_success()`: BUY 10 AAPL at $100.0, then SELL 5 AAPL at $150.0. Assert cash increases by $750.0, position quantity is 5, and avg_cost remains $100.0.
   - `test_trade_sell_insufficient_position()`: Attempt SELL when position is 0 or less than trade quantity. Assert HTTP 400 response with "Insufficient position".
   - `test_trade_missing_price()`: Attempt trade for ticker not in `PriceCache`. Assert HTTP 400 error.
</details>

Implement the background 30-second portfolio snapshot service, snapshot persistence logic, historical portfolio valuation endpoint `GET /api/portfolio/history`, and FastAPI lifespan management.
</step>
<details>
1. Create `backend/app/services/snapshot_service.py`:
   - `record_snapshot(db: aiosqlite.Connection, cache: PriceCache, user_id: str = "default") -> float`:
     - Read `cash_balance` from `users_profile`.
     - Fetch active positions (`quantity > 0`). Compute total market value using `PriceCache`.
     - Compute total value `total_val = round(cash + positions_value, 2)`.
     - Generate ISO-8601 timestamp `now_iso = datetime.now(timezone.utc).isoformat()`.
     - `INSERT INTO portfolio_snapshots (id, user_id, total_value, recorded_at) VALUES (?, ?, ?, ?)`.
     - Return `total_val`.
   - `SnapshotTask`:
     - Class initialized with `db_path: Path`, `cache: PriceCache`, `interval_seconds: int = 30`.
     - `start()`: Set `_running = True`, create `asyncio.create_task(self._run_loop())`.
     - `_run_loop()`: Loop while `_running`. In `try...except` block, open `get_db(db_path)`, call `record_snapshot()`, commit. Sleep `interval_seconds`.
     - `stop()`: Set `_running = False`, cancel `_task`, await task completion cleanly.

2. Update `backend/app/api/portfolio.py`:
   - Endpoint `GET /api/portfolio/history`:
     - Query `portfolio_snapshots` where `user_id = 'default'` ordered by `recorded_at ASC`.
     - Return `List[SnapshotResponse]`.

3. Update `backend/app/main.py`:
   - In lifespan context:
     - Instantiate `SnapshotTask(settings.DB_PATH, app.state.price_cache, interval_seconds=30)`.
     - Store `app.state.snapshot_task`.
     - Call `app.state.snapshot_task.start()`.
     - On shutdown: `await app.state.snapshot_task.stop()`.

4. Create `backend/tests/test_history.py`:
   - `test_post_trade_snapshot_trigger()`: Execute a trade and verify a new row is appended to `portfolio_snapshots`.
   - `test_background_snapshot_task()`: Instantiate `SnapshotTask` with a 1-second interval, start it, wait 2.5 seconds, stop it, and assert multiple snapshot records were created in `portfolio_snapshots`.
   - `test_get_portfolio_history()`: Seed 3 snapshot rows, request GET `/api/portfolio/history`, assert rows returned in ascending timestamp order with correct JSON fields (`id`, `total_value`, `recorded_at`).
</details>

     - If `cursor.rowcount == 0`, raise `HTTPException(404, "Ticker not found in watchlist")`.
     - Call `market_source.remove_ticker(ticker)` if `market_source` exists on `app.state`.
     - Return `{"status": "success", "ticker": ticker}`.
