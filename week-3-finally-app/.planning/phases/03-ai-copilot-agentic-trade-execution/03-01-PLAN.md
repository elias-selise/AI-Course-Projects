<objective>
Build the AI Copilot & Agentic Trade Execution engine for FinAlly, enabling natural language workstation control, live portfolio context injection, automated trade and watchlist execution, deterministic mock provider testing, and persistent conversation logging.

This plan covers:
1. Pydantic v2 data models for chat requests, structured LLM outputs, executed trade/watchlist results, and history log items (`backend/app/schemas/chat.py`).
2. Abstract LLM provider layer (`BaseLLMProvider`), OpenRouter integration (`openrouter/openai/gpt-oss-120b` via LiteLLM / httpx fallback), and deterministic regex-based `MockLLMProvider` (**AI-01**, **AI-03**).
3. Real-time system prompt context builder (`build_system_prompt()`) injecting cash balance, positions, watchlist items, and live price cache snapshot (**AI-01**).
4. Robust JSON response parser (`parse_llm_response()`) with markdown code block stripping and agentic action auto-execution engine calling Phase 2 portfolio accounting and watchlist engines (**AI-02**).
5. Chat history log persistence in SQLite `chat_messages` table and history management endpoints `GET /api/chat/history` and `DELETE /api/chat/history` (**AI-04**).
6. REST API controller `POST /api/chat` and main FastAPI app routing integration (**AI-01**).
7. Comprehensive automated pytest test suite (`backend/tests/test_chat.py`) executed via `uv run pytest`.
</objective>

<step>
Implement the Pydantic data schemas for chat requests/responses, the abstract `BaseLLMProvider` class, the OpenRouter LLM client, and the deterministic `MockLLMProvider` regex engine.
</step>
<details>
1. Create `backend/app/schemas/chat.py`:
   - `TradeAction`: `ticker: str` (sanitized uppercase), `side: Literal["buy", "sell"]`, `quantity: float` (`gt=0`).
   - `WatchlistAction`: `action: Literal["add", "remove"]`, `ticker: str` (sanitized uppercase).
   - `LLMResponseSchema`: `message: str`, `trades: List[TradeAction] = []`, `watchlist_changes: List[WatchlistAction] = []`.
   - `ChatRequest`: `message: str` (`min_length=1, max_length=2000`).
   - `ExecutedTradeResult`: `trade_id: Optional[str] = None`, `ticker: str`, `side: Literal["buy", "sell"]`, `quantity: float`, `price: float = 0.0`, `total_value: float = 0.0`, `status: Literal["success", "failed"] = "success"`, `error: Optional[str] = None`.
   - `ExecutedWatchlistResult`: `ticker: str`, `action: Literal["add", "remove"]`, `status: Literal["success", "failed"] = "success"`, `error: Optional[str] = None`.
   - `ChatResponse`: `message_id: str`, `user_message: str`, `assistant_message: str`, `executed_trades: List[ExecutedTradeResult] = []`, `executed_watchlist_changes: List[ExecutedWatchlistResult] = []`, `created_at: str`.
   - `ChatMessageResponse`: `id: str`, `role: Literal["user", "assistant"]`, `content: str`, `actions: Optional[Dict[str, Any]] = None`, `created_at: str`.

2. Create `backend/app/services/llm_provider.py`:
   - Abstract base class `BaseLLMProvider`:
     - `@abstractmethod async def generate_response(self, messages: List[Dict[str, str]]) -> str`.
   - Concrete class `OpenRouterLiteLLMProvider(BaseLLMProvider)`:
     - Constructor accepting `api_key: str` and optional `model_name: str = "openrouter/openai/gpt-oss-120b"`.
     - `generate_response()`: Try invoking `litellm.acompletion(model=self.model_name, api_key=self.api_key, messages=messages, response_format={"type": "json_object"}, temperature=0.2, timeout=30.0)`.
     - Fallback to `httpx.AsyncClient()` call targeting `https://openrouter.ai/api/v1/chat/completions` with bearer authentication if LiteLLM is not installed.
   - Concrete class `MockLLMProvider(BaseLLMProvider)`:
     - `generate_response()`: Parse last message content with regular expressions.
     - Match regex patterns for:
       - Buy trades: `buy\s+(\d+(?:\.\d+)?)\s*(?:shares\s+of\s+)?([a-zA-Z]{1,5})` -> `{"trades": [{"ticker": ticker, "side": "buy", "quantity": qty}]}`
       - Sell trades: `sell\s+(\d+(?:\.\d+)?)\s*(?:shares\s+of\s+)?([a-zA-Z]{1,5})` -> `{"trades": [{"ticker": ticker, "side": "sell", "quantity": qty}]}`
       - Add watchlist: `add\s+([a-zA-Z]{1,5})\s+to\s+watchlist` -> `{"watchlist_changes": [{"action": "add", "ticker": ticker}]}`
       - Remove watchlist: `(remove|delete)\s+([a-zA-Z]{1,5})\s+from\s+watchlist` -> `{"watchlist_changes": [{"action": "remove", "ticker": ticker}]}`
       - General queries: Return descriptive natural language message with empty trade and watchlist arrays.
     - Serialize JSON string response matching `LLMResponseSchema` format.
   - Factory function `get_llm_provider(settings: Settings) -> BaseLLMProvider`:
     - If `settings.LLM_MOCK` is True or `settings.OPENROUTER_API_KEY` is empty/None, log info message and return `MockLLMProvider()`.
     - Otherwise return `OpenRouterLiteLLMProvider(api_key=settings.OPENROUTER_API_KEY)`.

3. Create `backend/tests/test_chat.py`:
   - `test_mock_provider_buy_intent()`: Invoke `MockLLMProvider.generate_response()` with "Buy 10 shares of AAPL". Assert returned JSON contains `trades` array with ticker `AAPL`, side `buy`, quantity `10.0`.
   - `test_mock_provider_sell_intent()`: Invoke with "Sell 5 shares of TSLA". Assert `trades` array contains ticker `TSLA`, side `sell`, quantity `5.0`.
   - `test_mock_provider_watchlist_intent()`: Invoke with "Add NVDA to watchlist". Assert `watchlist_changes` array contains action `add`, ticker `NVDA`.
   - `test_mock_provider_general_query()`: Invoke with "How is my portfolio doing?". Assert returned JSON contains message text and empty action arrays.
</details>

<name>Structured JSON Output Parser & Agentic Action Auto-Execution Engine (AI-02)</name>
<files>
- backend/app/services/chat_service.py
- backend/tests/test_chat.py
</files>
<step>
Implement the raw LLM output JSON parser with markdown code fence stripping and the agentic action auto-execution pipeline that executes trade orders and updates watchlist state.
</step>
<details>
1. Create `backend/app/services/chat_service.py`:
   - Function `parse_llm_response(raw_text: str) -> LLMResponseSchema`:
     - Strip leading/trailing whitespace.
     - Detect and strip markdown code block fences (e.g. ` ```json ... ``` ` or ` ``` ... ``` `).
     - Parse JSON via `json.loads()` and validate using `LLMResponseSchema(**data)`.
     - Handle parsing or validation exceptions gracefully by returning fallback `LLMResponseSchema(message=raw_text, trades=[], watchlist_changes=[])`.

   - Function `process_chat_message(db: aiosqlite.Connection, cache: PriceCache, provider: BaseLLMProvider, user_message: str, market_source: Any = None, user_id: str = "default") -> ChatResponse`:
     - Generate ISO-8601 timestamp and unique UUID for user message.
     - Save user message to `chat_messages` table: `INSERT INTO chat_messages (id, user_id, role, content, created_at) VALUES (?, ?, 'user', ?, ?)`. Commit transaction.
     - Fetch recent conversation history (last 10 turns) from `chat_messages` table ordered by `created_at ASC`.
     - Calculate current portfolio via `calculate_portfolio(db, cache, user_id)`.
     - Query current watchlist items from database.
     - Build system prompt via `build_system_prompt(portfolio, watchlist_items, cache)`.
     - Construct LLM message payload: `[{"role": "system", "content": system_prompt}] + history_messages`.
     - Call `raw_response = await provider.generate_response(messages)`.
     - Parse response via `llm_schema = parse_llm_response(raw_response)`.
     - Loop over `llm_schema.trades`:
       - Construct `TradeRequest(ticker=trade_act.ticker, side=trade_act.side, quantity=trade_act.quantity)`.
       - Execute trade via `execute_trade(db, cache, trade_req, user_id)`.
       - Append `ExecutedTradeResult` with status `"success"` and trade metadata.
       - On exception (`ValueError`), log error and append `ExecutedTradeResult` with status `"failed"` and error details.
     - Loop over `llm_schema.watchlist_changes`:
       - If `action == "add"`: Insert into `watchlist` table (if not existing) and notify `market_source.add_ticker(ticker)` if market source is active.
       - If `action == "remove"`: Delete from `watchlist` table and notify `market_source.remove_ticker(ticker)`.
       - Append `ExecutedWatchlistResult` with status `"success"`.
       - On exception, log error and append `ExecutedWatchlistResult` with status `"failed"`.
     - Serialize executed actions into JSON string: `actions_json = json.dumps({"trades": [...], "watchlist_changes": [...]})`.
     - Save assistant message to `chat_messages` table: `INSERT INTO chat_messages (id, user_id, role, content, actions, created_at) VALUES (?, ?, 'assistant', ?, ?, ?)`. Commit transaction.
     - Return `ChatResponse`.

2. Expand `backend/tests/test_chat.py`:
   - `test_parse_llm_response_markdown_strip()`: Test raw string enclosed in ` ```json {"message": "hello", "trades": [], "watchlist_changes": []} ``` ` parses correctly into `LLMResponseSchema`.
   - `test_auto_execution_buy_trade()`:
     - Set up test database with initial $10,000 cash balance and price cache (AAPL @ $150.0).
     - Call `process_chat_message()` with user message "Buy 10 shares of AAPL".
     - Assert returned `ChatResponse` contains `executed_trades` with 1 successful trade (10 AAPL @ $150.0).
     - Query database `users_profile` and assert cash balance decreased by $1,500.0 ($8,500.0 remaining).
     - Query `positions` table and assert position record exists for AAPL.
   - `test_auto_execution_sell_trade()`:
     - Seed position (10 AAPL @ $150.0) in test database.
     - Call `process_chat_message()` with user message "Sell 5 shares of AAPL".
     - Assert `executed_trades` shows successful sell of 5 AAPL.
     - Assert position quantity is reduced to 5.
   - `test_auto_execution_watchlist_add()`:
     - Call `process_chat_message()` with "Add NVDA to watchlist".
     - Assert `executed_watchlist_changes` contains action `add` for ticker `NVDA`.
     - Query `watchlist` table and assert NVDA row exists.
   - `test_auto_execution_failed_trade_insufficient_funds()`:
     - Call `process_chat_message()` with "Buy 1000 shares of NVDA" (at $800.0 each = $800,000 > $10,000 cash).
     - Assert `executed_trades` record has status `"failed"` with "Insufficient funds" error message, and endpoint completes without raising 500 server error.
</details>

<step>
Implement the REST API router for AI Copilot chat endpoints (`POST /api/chat`, `GET /api/chat/history`, `DELETE /api/chat/history`).
</step>
<details>
1. Create `backend/app/api/chat.py`:
   - APIRouter with prefix `/api/chat`, tag `"AI Copilot"`.
   - Endpoint `POST /api/chat`:
     - Accept `ChatRequest` JSON payload.
     - Obtain `PriceCache` from `request.app.state.price_cache`.
     - Obtain `market_source` from `request.app.state.market_source` (if present).
     - Obtain `settings` from `get_settings()`.
     - Resolve LLM provider via `get_llm_provider(settings)`.
     - Open DB context manager `get_db(settings.DB_PATH)`.
     - Call `process_chat_message()` and return `ChatResponse`.
     - Handle internal errors by raising `HTTPException(500, detail=str(e))`.
   - Endpoint `GET /api/chat/history`:
     - Open DB connection `get_db(settings.DB_PATH)`.
     - Query `chat_messages` table for `user_id = 'default'` ordered by `created_at ASC`.
     - Parse `actions` JSON column if present.
     - Return `List[ChatMessageResponse]`.
   - Endpoint `DELETE /api/chat/history`:
     - Open DB connection `get_db(settings.DB_PATH)`.
     - Execute `DELETE FROM chat_messages WHERE user_id = 'default'`.
     - Commit transaction.
     - Return `{"status": "success", "message": "Chat history cleared."}`.

2. Expand `backend/tests/test_chat.py`:
   - `test_post_chat_endpoint()`:
     - Use `httpx.AsyncClient` with `ASGITransport(app=app)` to send `POST /api/chat` with `{"message": "Hello FinAlly"}`.
     - Assert HTTP 200 OK status code and JSON structure matching `ChatResponse`.
   - `test_get_chat_history_endpoint()`:
     - Send chat prompt to populate history.
     - Request `GET /api/chat/history`.
     - Assert returned array contains user message and assistant response in chronological order with correct roles and IDs.
   - `test_clear_chat_history_endpoint()`:
     - Request `DELETE /api/chat/history`.
     - Assert HTTP 200 response.
     - Request `GET /api/chat/history` and assert returned list is empty `[]`.
</details>
