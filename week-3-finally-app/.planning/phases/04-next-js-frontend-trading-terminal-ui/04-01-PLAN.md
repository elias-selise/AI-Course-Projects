<objective>
Build the Next.js single-page frontend application for the FinAlly AI Trading Workstation.

This plan covers:
1. Next.js 14 App Router project setup with TypeScript, Tailwind CSS dark theme design system (`#0d1117`, `#1a1a2e`, `#ecad0a`), and static HTML export configuration (`output: 'export'`) (**UI-01**).
2. Terminal Header component displaying total portfolio value, cash balance, and real-time SSE stream status dot (**UI-02**).
3. TypeScript type definitions, REST API client wrapper (`api.ts`), centralized Zustand store (`useTerminalStore`), and custom SSE market data stream hook (`useMarketStream`) with sparkline buffers and 500ms flash animations (**UI-03** infrastructure).
4. Live Watchlist Grid with sparklines and ticker selection (**UI-03**) alongside the Interactive Main Price Chart component (**UI-04**).
5. Portfolio views including Portfolio Heatmap Treemap (**UI-05**), Portfolio P&L Line Chart (**UI-06**), Positions Table (**UI-07**), and Order Entry Trade Bar (**UI-08**).
6. AI Copilot Chat Sidebar Panel with prompt submission, message history, loading states, and inline action confirmation cards for executed trades/watchlist changes (**UI-09**).
7. End-to-end static export build verification (`npm run build`).
</objective>

<step>
Implement core data models, REST client functions for backend endpoints, central Zustand store, and browser EventSource subscriber hook with rolling sparklines and flash state handling.
</step>
<details>
1. Create `frontend/src/types/index.ts`:
   - Export interfaces: `PriceTick`, `Position`, `Portfolio`, `PortfolioSnapshot`, `WatchlistItem`, `TradeRequest`, `ExecutedAction`, `ChatMessage`.

2. Create `frontend/src/lib/api.ts`:
   - Implement typed async fetch client functions using relative endpoint paths (`/api/*`):
     - `getPortfolio(): Promise<Portfolio>` -> `GET /api/portfolio`
     - `executeTrade(trade: TradeRequest): Promise<any>` -> `POST /api/portfolio/trade`
     - `getPortfolioHistory(): Promise<PortfolioSnapshot[]>` -> `GET /api/portfolio/history`
     - `getWatchlist(): Promise<WatchlistItem[]>` -> `GET /api/watchlist`
     - `addWatchlist(ticker: string): Promise<any>` -> `POST /api/watchlist`
     - `deleteWatchlist(ticker: string): Promise<any>` -> `DELETE /api/watchlist/{ticker}`
     - `getChatHistory(): Promise<ChatMessage[]>` -> `GET /api/chat/history`
     - `sendChatMessage(message: string): Promise<any>` -> `POST /api/chat`

3. Create `frontend/src/hooks/useMarketStream.ts`:
   - State: `status` ('connected' | 'reconnecting' | 'disconnected'), `prices` (`Record<string, PriceTick>`), `sparklines` (`Record<string, number[]>`), `flashes` (`Record<string, 'up' | 'down' | null>`).
   - `useEffect` establishing `new EventSource('/api/stream/prices')`.
   - On SSE message: parse tick data, update `prices` map, push price to rolling 30-tick array in `sparklines`, set 500ms flash state in `flashes` and clear with `setTimeout`.
   - Cleanup: `eventSource.close()`, clear timeouts, set status to `disconnected`.

4. Create `frontend/src/store/useTerminalStore.ts`:
   - Zustand store holding state: `selectedTicker`, `portfolio`, `watchlist`, `history`, `chatHistory`, `isLoadingChat`.
   - Actions: `setSelectedTicker(ticker)`, `fetchPortfolio()`, `fetchWatchlist()`, `fetchHistory()`, `fetchChatHistory()`, `sendChatMessage(msg)`, `executeTrade(ticker, side, qty)`, `addWatchlistTicker(ticker)`, `removeWatchlistTicker(ticker)`.
   - Helper function `refreshAll()` triggering `fetchPortfolio()`, `fetchWatchlist()`, `fetchHistory()` after trades or AI actions.
</details>
